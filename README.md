# Fix Cost Basis

Cost basis in Quicken is often incorrect, and must be corrected by
correcting purchase lots.  Lots in Schwab are assumed correct.
You can extract logs from Schwab, but only
a security at a time.  You can get all of the lots for an account from
Quicken.

Compare these and generate changes to Quicken to synchronize lots.
