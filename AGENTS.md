# Project Instructions

## Application

This is a set of Python scripts for working with Quicken.

## Tools

- Use `uv` for all Python dependency management.
- Install packages with `uv add` or `uv add --dev`.
- Run Python programs with `uv run`.
- Run tests with:
  uv run pytest -n auto
- Do not use pip, venv activation, or python directly unless explicitly requested.
